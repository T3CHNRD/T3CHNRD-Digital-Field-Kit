# Deployment and Setup SOP

Use this procedure for new-device preparation, approved software installation, workstation restoration, or repeatable setup work.

## Preparation

- Confirm the device owner, role, hostname, network, licensing, and required applications.
- Confirm the source and license status of every installer or payload.
- Record the starting OS version, architecture, storage, encryption state, and local administrator status.
- Use the installed or portable mode appropriate to the engagement.

## Execution order

1. Capture a baseline device report.
2. Apply updates and vendor-supported drivers as appropriate.
3. Install only approved applications and record their source and version.
4. Configure the required network, security, and user settings.
5. Validate startup, connectivity, updates, security controls, and required business applications.
6. Capture a final report and handoff notes.

## Guardrails

- Do not use unverified replacement payloads for missing original tools.
- Keep Win11Debloat and WinUtil workflows excluded unless their exact approved bundles are present.
- Do not remove existing software or profiles without documented approval.

## Handoff criteria

The device has a named owner, documented software state, working network, validated security controls, completed updates, and a clear list of remaining actions.
