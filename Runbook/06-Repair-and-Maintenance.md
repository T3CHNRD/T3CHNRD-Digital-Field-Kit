# Repair and Maintenance SOP

Use this procedure for disk pressure, temporary-file buildup, system-file problems, update issues, performance complaints, or routine maintenance.

## Before changes

- Record the symptom, user impact, free space, uptime, recent changes, and backup status.
- Close user applications when a repair may restart services or require a reboot.
- Confirm that the selected action is appropriate for the device and has approval.

## Repair order

1. Start with device information, disk space, and performance evidence.
2. Check update and service state.
3. Run targeted cleanup or repair checks.
4. Reboot only when required and after confirming the user can continue work.
5. Re-run the original diagnostic and compare the result.

## Guardrails

- Do not disable BitLocker or security controls as a generic repair step.
- Do not delete user data or unknown files to create space.
- Treat BIOS, firmware, driver, and disk repair actions as higher risk.
- Keep the original output before applying a change.

## Closeout

Document the action, exit code, reboot status, before and after measurements, remaining symptoms, and recommended follow-up.
