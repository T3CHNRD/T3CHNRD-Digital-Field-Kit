# T3CHNRD Digital Field Kit

Portable and installable technician toolkit for Windows diagnostics, repair, security review, deployment, Runbook documentation, and future offline AI-assisted diagnosis.

## Working product name

**T3CHNRD Digital Field Kit**

The repository name can be renamed later; the current GitHub connection does not expose repository-administration rename controls.

## Current direction

- Windows GUI toolkit with embedded diagnostic execution
- Portable USB/external-drive mode and installed mode
- Searchable Runbook Wiki
- Offline/local AI diagnostic assistant (planned)
- macOS collectors and scripts (planned)
- AI-assisted Runbook draft creation for newly solved issues (planned; technician review required before Verified status)
