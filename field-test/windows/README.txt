T3CHNRD Digital Field Kit v12 - Windows Field Test

1. Extract the ZIP to a normal folder or external drive.
2. Open field-test\windows.
3. Double-click START-T3DFK.cmd.

This is a no-build Windows field-test shell for the rebuilt UI/runner and is not the final native Avalonia executable.
The final native executables are produced by GitHub Actions from src\T3DFK.App for Windows x64, macOS Intel, and macOS Apple Silicon.
