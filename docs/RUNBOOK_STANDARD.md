# Runbook Article Standard

Each article should use this structure:

```markdown
# Procedure / Issue Title

**Category:** Network / Windows / Exchange / Oracle / Printer / etc.  
**Platform:** Windows / macOS / Cross-platform  
**Status:** Draft / Verified / Deprecated  
**Last Updated:** YYYY-MM-DD

## Symptoms
What the user or technician sees.

## Applies To
Systems, versions, applications, departments, or device classes.

## Cause
Confirmed cause, or `Unknown` until proven.

## Resolution
Numbered, reproducible steps.

## Verification
How to prove the fix worked.

## Rollback / Recovery
How to reverse the change or recover if it fails.

## Related Toolkit Tools
Relevant T3CHNRD Digital Field Kit tools.

## Notes / References
Tickets, screenshots, vendor documentation, or related Runbook articles.
```

AI-generated material must start as **Draft** and be reviewed before being marked Verified.
